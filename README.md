# Gesture-Controlled Touchless Healthcare System

## Overview

The Gesture-Controlled Touchless Healthcare System is an AI-powered solution designed for hospitals, operation theaters, and clinical environments. It enables healthcare professionals to interact with medical systems using hand gestures, voice commands, and facial recognition without physically touching devices.

The system helps maintain sterility, improve workflow efficiency, reduce contamination risks, and enhance patient care.

## Problem Statement

In medical environments, touching shared devices can increase the risk of contamination and infection. Healthcare professionals often require hands-free access to patient records, medical images, and hospital systems while maintaining sterile conditions.

## Solution

This project uses Computer Vision and Artificial Intelligence to provide a touchless interaction platform through:

- Hand Gesture Recognition
- Voice Command Processing
- Facial Recognition Authentication
- Real-Time System Control

## Features

### Gesture Recognition
- Open Palm Detection
- Swipe Left / Right Navigation
- Zoom In / Zoom Out
- Menu Selection

### Facial Recognition
- Secure Staff Authentication
- Role-Based Access Control

### Voice Assistance
- Hands-Free Commands
- Quick Information Retrieval

### Healthcare Integration
- Patient Record Navigation

- Contactless System Interaction

## System Workflow

1. Camera captures live video feed.
2. MediaPipe detects hand landmarks.
3. AI model identifies gestures.
4. Commands are mapped to system actions.
5. User receives real-time feedback.
6. Facial recognition verifies authorized users.
